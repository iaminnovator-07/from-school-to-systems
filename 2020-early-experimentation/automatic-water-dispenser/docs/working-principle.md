# ⚙ Working Principle

The Automatic Water Dispenser system uses ultrasonic sensing for touchless automation.

---

# 📏 Proximity Detection

The ultrasonic sensor continuously measures nearby object distance.

### No Object Detected
- Dispensing system remains inactive

### Object Detected
- Servo motor activates
- Water dispensing mechanism operates automatically

---

# 🧠 Embedded Automation Workflow

```txt
Object Detection
        ↓
 Ultrasonic Sensor
        ↓
Arduino Processing
        ↓
Automation Logic
        ↓
 Servo Activation
        ↓
Water Dispensing
```

The system demonstrates basic touchless automation and embedded interaction concepts.
