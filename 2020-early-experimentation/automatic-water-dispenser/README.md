# 🌌 Overview

**Automatic Water Dispenser** was developed during the early experimentation phase of the SYGNIX journey as an exploration into touchless automation systems and sensor-based embedded control mechanisms.

The project focused on understanding how embedded systems could automate water dispensing using proximity detection and intelligent response workflows.

This prototype introduced foundational concepts such as:
- touchless automation
- sensor-triggered systems
- embedded response logic
- automation workflows
- real-time object detection

The project became one of the earliest practical explorations into smart automation and user-interaction systems.

# ⚙ Working Principle

The system uses an ultrasonic sensor to detect nearby objects or hand movement.

### Workflow

1. Ultrasonic sensor continuously measures object distance.
2. Arduino processes real-time distance values.
3. When an object enters detection range:
   - servo motor activates
   - dispensing mechanism operates
4. System automatically resets after dispensing.

This creates a touchless embedded water-dispensing automation system.
