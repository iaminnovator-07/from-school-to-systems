# 🛠 Components Used

## Hardware Components

• Arduino UNO  
• Ultrasonic Sensor (HC-SR04)  
• Servo Motor  
• Breadboard  
• Jumper Wires  
• USB Cable

---

## Purpose of Components

### Arduino UNO
Main embedded controller handling automation logic.

### Ultrasonic Sensor
Detects object or hand proximity.

### Servo Motor
Controls automated dispensing mechanism.

### Breadboard & Jumper Wires
Used for hardware prototyping and circuit setup.
