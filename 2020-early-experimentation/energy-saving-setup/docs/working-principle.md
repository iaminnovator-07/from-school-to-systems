# ⚙ Working Principle

The Energy Saving Setup system automates power usage using environmental sensing and intelligent control workflows.

---

# 🌗 Environmental Monitoring

The LDR sensor continuously detects surrounding brightness conditions.

### Bright Conditions
- Connected systems remain OFF
- Energy consumption is minimized

### Low-Light Conditions
- Relay activates automatically
- Connected systems turn ON

---

# 🧠 Embedded Automation Workflow

```txt
Environmental Conditions
            ↓
        LDR Sensor
            ↓
    Arduino Processing
            ↓
     Automation Logic
            ↓
      Relay Activation
            ↓
   Energy Optimization
```

The system demonstrates basic intelligent automation and energy-efficient embedded system concepts.
