# 🌌 Overview

**Energy Saving Setup** was developed during the early experimentation phase of the SYGNIX journey as an exploration into intelligent energy optimization systems and automation-driven power management concepts.

The project focused on understanding how embedded systems could reduce unnecessary power consumption using environmental sensing and automated control workflows.

This prototype introduced foundational concepts such as:
- intelligent automation
- energy-efficient systems
- sensor-driven control logic
- embedded optimization workflows
- environmental monitoring

The project became one of the earliest explorations into sustainable and efficient automation architectures.

# ⚙ Working Principle

The system uses environmental sensing to automate power usage.

### Workflow

1. LDR sensor continuously monitors environmental brightness.
2. Arduino processes real-time sensor values.
3. During low-light conditions:
   - connected devices activate automatically
4. During bright conditions:
   - unnecessary systems remain OFF

This creates an intelligent energy-saving embedded automation system.
