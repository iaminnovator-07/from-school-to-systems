# 🌌 Overview

**Ultrasonic Distance Measurement System** was developed during the early experimentation phase of the SYGNIX journey as an exploration into real-time distance sensing and embedded measurement architectures.

The project focused on understanding how ultrasonic waves could be used for object detection and accurate distance calculation through embedded systems.

This prototype introduced foundational concepts such as:
- ultrasonic sensing
- real-time distance monitoring
- object detection systems
- embedded measurement workflows
- sensor-driven analytics

The project became one of the earliest explorations into intelligent sensing and real-time monitoring systems.

# ⚙ Working Principle

The HC-SR04 ultrasonic sensor emits ultrasonic waves toward nearby objects.

### Workflow

1. Ultrasonic sensor sends ultrasonic pulse.
2. Waves reflect back after hitting an object.
3. Arduino measures echo return time.
4. Embedded logic calculates object distance.

This creates a basic embedded distance-monitoring and object-detection system.
