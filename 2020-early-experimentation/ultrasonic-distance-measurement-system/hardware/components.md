# 🛠 Components Used

## Hardware Components

• Arduino UNO  
• HC-SR04 Ultrasonic Sensor  
• LEDs  
• Breadboard  
• Jumper Wires  
• Resistors  
• USB Cable

---

## Purpose of Components

### Arduino UNO
Main embedded controller handling measurement logic.

### HC-SR04 Ultrasonic Sensor
Detects object distance using ultrasonic wave reflection.

### LEDs
Provide close-range distance indication.

### Breadboard & Jumper Wires
Used for hardware prototyping and sensor interfacing.
