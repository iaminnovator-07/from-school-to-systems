## Purpose of Components

### Arduino UNO
Main embedded controller handling heartbeat monitoring logic.

### Pulse Sensor
Detects heartbeat and pulse fluctuations.

### LEDs
Provide heartbeat activity indication.

### Breadboard & Jumper Wires
Used for hardware prototyping and sensor interfacing.
