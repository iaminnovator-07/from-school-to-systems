# ⚙ Working Principle

The HeartBeat Monitoring System uses a pulse sensor to detect heartbeat activity through biometric signal sensing.

---

# ❤️ Pulse Detection

The pulse sensor detects small blood-flow variations generated during heartbeats.

### Monitoring Workflow
- User places finger on sensor
- Sensor captures pulse signal
- Arduino processes analog data
- Real-time heartbeat values are monitored

---

# 🧠 Embedded Monitoring Workflow

```txt
Heartbeat Signal
        ↓
    Pulse Sensor
        ↓
 Arduino Processing
        ↓
 Signal Analysis
        ↓
 Monitoring Output
```

The system demonstrates basic biomedical sensing and embedded healthcare monitoring concepts.
