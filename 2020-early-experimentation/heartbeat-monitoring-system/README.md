# 🌌 Overview

**HeartBeat Monitoring System** was developed during the early experimentation phase of the SYGNIX journey as an exploration into biomedical sensing and embedded healthcare monitoring systems.

The project focused on understanding how pulse sensors could detect heartbeat signals and enable real-time biometric monitoring through embedded systems.

This prototype introduced foundational concepts such as:
- biomedical sensing
- pulse signal monitoring
- real-time data acquisition
- embedded healthcare systems
- sensor-driven monitoring workflows

The project became one of the earliest explorations into healthcare-oriented embedded architectures.

# ⚙ Working Principle

The pulse sensor detects small changes in blood flow caused by heartbeats.

### Workflow

1. User places finger on pulse sensor.
2. Sensor detects pulse fluctuations.
3. Arduino processes analog signal values.
4. Real-time heartbeat activity is monitored and displayed.

This creates a basic embedded biometric monitoring system.
