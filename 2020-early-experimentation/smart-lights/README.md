# 🌌 Overview

**Smart Lights** was one of the earliest embedded systems experimentation projects developed during the foundational phase of the SYGNIX engineering journey.

The project focused on understanding how automation systems could intelligently control lighting using sensor-based environmental input and embedded control logic.

Although simple in architecture, this system played an important role in introducing concepts such as:

- embedded systems
- automation workflows
- sensor interfacing
- environmental sensing
- energy-efficient logic
- hardware/software interaction

This project represents one of the earliest explorations into intelligent automation systems during school years.

# ⚙ Working Principle

The system operates using an **LDR (Light Dependent Resistor)** connected to the Arduino.

### Workflow

1. LDR continuously reads environmental brightness levels.
2. Arduino processes analog sensor values.
3. During low-light conditions:
   - LEDs automatically turn ON
4. During bright conditions:
   - LEDs remain OFF

This creates a basic intelligent lighting automation system.
