# 🛠 Components Used

## Hardware Components

• Arduino UNO  
• LDR Sensor  
• IR Sensor  
• LEDs  
• Breadboard  
• Jumper Wires  
• Resistors  
• USB Cable

---

## Purpose of Components

### Arduino UNO
Main embedded controller responsible for automation logic.

### LDR Sensor
Detects surrounding brightness levels.

### IR Sensor
Detects nearby movement or motion.

### LEDs
Simulate intelligent street lights.

### Breadboard & Jumper Wires
Used for temporary hardware prototyping and circuit connections.
