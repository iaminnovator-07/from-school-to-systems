# 🛠 Components Used

## Hardware Components

• Arduino UNO  
• PIR Motion Sensor  
• Buzzer Module  
• LEDs  
• Breadboard  
• Jumper Wires  
• Resistors  
• USB Cable

---

## Purpose of Components

### Arduino UNO
Main embedded controller handling security automation logic.

### PIR Motion Sensor
Detects nearby human movement and motion activity.

### Buzzer Module
Generates intrusion alert sound during detection.

### LEDs
Provide visual security alert indication.

### Breadboard & Jumper Wires
Used for hardware prototyping and sensor interfacing.
