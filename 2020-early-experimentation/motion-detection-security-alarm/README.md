# 🌌 Overview

**Motion Detection Security Alarm** was developed during the early experimentation phase of the SYGNIX journey as an exploration into embedded security systems and motion-based intrusion detection architectures.

The project focused on understanding how PIR motion sensors could detect human movement and trigger automated alert systems through embedded processing logic.

This prototype introduced foundational concepts such as:
- motion detection
- embedded security systems
- intrusion monitoring
- automated alert mechanisms
- sensor-driven surveillance workflows

The project became one of the earliest explorations into intelligent embedded safety and monitoring systems.

# ⚙ Working Principle

The system uses a PIR motion sensor to detect nearby human movement.

### Workflow

1. PIR sensor continuously monitors movement.
2. Arduino processes real-time sensor signals.
3. During motion detection:
   - buzzer activates
   - LED alert triggers
4. Security monitoring workflow executes automatically.

This creates a basic embedded intrusion detection and security alert system.
