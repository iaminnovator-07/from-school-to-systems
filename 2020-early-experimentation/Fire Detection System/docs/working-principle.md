# ⚙ Working Principle

The Fire Alarm & Fire Detection System continuously monitors surrounding environmental conditions using a flame sensor.

---

# 🔥 Hazard Detection

The flame sensor detects abnormal fire/light intensity levels.

### Normal Conditions
- Buzzer remains OFF
- LED remains OFF

### Fire Detection
- Buzzer activates instantly
- LED alert activates
- Emergency response logic executes

---

# 🧠 Embedded Automation Workflow

```txt
Environmental Hazard
          ↓
      Flame Sensor
          ↓
   Arduino Processing
          ↓
    Detection Logic
          ↓
 Emergency Alert System
```

The system demonstrates basic embedded safety automation and real-time hazard monitoring concepts.
