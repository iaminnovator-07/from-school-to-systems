# 🌌 Overview

**Fire Alarm & Fire Detection System** was developed during the early experimentation phase of the SYGNIX journey as an exploration into embedded safety systems and environmental hazard detection.

The project focused on understanding how sensors and embedded systems could detect fire or abnormal environmental conditions and trigger automated alerts.

This prototype introduced foundational concepts such as:
- environmental hazard detection
- embedded safety mechanisms
- real-time monitoring
- sensor-triggered alert systems
- automation-based emergency response

The project became one of the earliest explorations into safety-oriented intelligent systems.

# ⚙ Working Principle

The flame sensor continuously monitors surrounding environmental conditions.

### Workflow

1. Flame sensor detects fire/light intensity.
2. Arduino reads sensor values in real time.
3. During fire detection:
   - buzzer activates
   - LED alert triggers
4. Automated emergency response logic executes instantly.

This creates a basic embedded fire-alert and safety-monitoring system.
