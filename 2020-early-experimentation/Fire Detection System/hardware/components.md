# 🛠 Components Used

## Hardware Components

• Arduino UNO  
• Flame Sensor  
• Buzzer Module  
• LEDs  
• Breadboard  
• Jumper Wires  
• Resistors  
• USB Cable

---

## Purpose of Components

### Arduino UNO
Main embedded controller handling detection logic.

### Flame Sensor
Detects fire or abnormal light intensity.

### Buzzer Module
Generates emergency alert sound.

### LEDs
Provide visual hazard indication.

### Breadboard & Jumper Wires
Used for hardware prototyping and circuit connections.
