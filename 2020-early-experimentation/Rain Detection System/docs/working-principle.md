# ⚙ Working Principle

The Rain Detection System continuously monitors environmental moisture levels using a rain sensor module.

---

# 🌧 Rainfall Detection

The sensor surface detects water droplets through conductive sensing mechanisms.

### Dry Conditions
- LED remains OFF

### Rain Detection
- LED automatically activates
- Arduino processes moisture input values

---

# 🧠 Embedded Automation Workflow

```txt
Rain / Moisture
        ↓
   Rain Sensor
        ↓
 Arduino Processing
        ↓
 Detection Logic
        ↓
 Alert Generation
```

The system demonstrates basic environmental sensing and weather-responsive automation concepts.
