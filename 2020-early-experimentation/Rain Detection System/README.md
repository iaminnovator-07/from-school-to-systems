# 🌌 Overview

**Rain Detection System** was developed during the early experimentation phase of the SYGNIX journey as an exploration into environmental sensing and weather-responsive automation systems.

The project focused on understanding how embedded systems could detect rainfall conditions using sensor-based inputs and trigger automated responses.

This prototype introduced foundational concepts such as:
- environmental monitoring
- sensor calibration
- analog signal processing
- weather-responsive automation
- embedded sensing systems

Although simple in implementation, the project played an important role in understanding real-world sensing workflows and automation logic.

# ⚙ Working Principle

The rain sensor module detects water droplets through conductive sensing.

### Workflow

1. Rain sensor continuously monitors moisture levels.
2. Arduino reads analog sensor values.
3. During rainfall detection:
   - LED indicators activate
4. System generates automated environmental response.

This creates a basic weather-responsive embedded sensing system.
