## Purpose of Components

### Arduino UNO
Main embedded controller responsible for processing sensor inputs.

### Rain Sensor Module
Detects rainfall and moisture conditions.

### LEDs
Provide rainfall indication alerts.

### Breadboard & Jumper Wires
Used for prototype hardware setup and circuit connections.
