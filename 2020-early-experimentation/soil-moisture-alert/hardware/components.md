# 🛠 Components Used

## Hardware Components

• Arduino UNO  
• Soil Moisture Sensor  
• Buzzer Module  
• LEDs  
• Breadboard  
• Jumper Wires  
• Resistors  
• USB Cable

---

## Purpose of Components

### Arduino UNO
Main embedded controller handling environmental monitoring logic.

### Soil Moisture Sensor
Detects moisture levels in soil conditions.

### Buzzer Module
Generates alerts during dry-soil conditions.

### LEDs
Provide visual moisture-status indication.

### Breadboard & Jumper Wires
Used for hardware prototyping and sensor interfacing.
