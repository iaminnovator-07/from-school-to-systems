# 🌌 Overview

**Soil Moisture Alert** was developed during the early experimentation phase of the SYGNIX journey as an exploration into environmental sensing and smart agricultural monitoring systems.

The project focused on understanding how embedded systems could detect soil moisture conditions and trigger automated alerts for irrigation and monitoring workflows.

This prototype introduced foundational concepts such as:
- soil moisture sensing
- environmental monitoring
- smart agriculture systems
- embedded automation
- real-time sensor processing

The project became one of the earliest explorations into intelligent agricultural and environmental automation architectures.

# ⚙ Working Principle

The system uses a soil moisture sensor to detect environmental moisture conditions.

### Workflow

1. Soil moisture sensor continuously monitors moisture levels.
2. Arduino reads analog sensor values.
3. During dry soil conditions:
   - buzzer activates
   - LED alert triggers
4. Real-time environmental monitoring workflow executes.

This creates a basic smart agriculture and embedded soil-monitoring system.
