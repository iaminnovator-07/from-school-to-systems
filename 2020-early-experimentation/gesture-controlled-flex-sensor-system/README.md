# 🌌 Overview

**Gesture Controlled Flex Sensor System** was developed during the early experimentation phase of the SYGNIX journey as an exploration into human-machine interaction and gesture-based embedded automation systems.

The project focused on understanding how flex sensors could detect finger or hand movement and translate physical gestures into automated electronic responses.

This prototype introduced foundational concepts such as:
- gesture recognition
- flex sensor interfacing
- embedded interaction systems
- real-time sensor processing
- intelligent automation workflows

The project became one of the earliest explorations into intuitive human-controlled embedded systems.

# ⚙ Working Principle

The system uses a flex sensor to detect finger movement and bending angles.

### Workflow

1. Flex sensor resistance changes during bending.
2. Arduino continuously reads analog sensor values.
3. Embedded logic processes gesture input.
4. Outputs activate based on gesture conditions.

This creates a basic gesture-controlled embedded interaction system.
