# ⚙ Working Principle

The Gesture Controlled Flex Sensor System detects finger movement and bending using a flex sensor.

---

# 🤚 Gesture Detection

The flex sensor changes resistance during bending movement.

### Normal Position
- Default output state remains active

### Finger Bend / Gesture
- Sensor value changes
- Arduino processes gesture input
- Output behavior changes automatically

---

# 🧠 Embedded Interaction Workflow

```txt
Hand Gesture
      ↓
  Flex Sensor
      ↓
Arduino Processing
      ↓
Gesture Logic
      ↓
 Output Control
```

The system demonstrates basic gesture recognition and human-machine interaction concepts.
