# 🛠 Components Used

## Hardware Components

• Arduino UNO  
• Flex Sensor  
• LEDs  
• Breadboard  
• Jumper Wires  
• Resistors  
• USB Cable

---

## Purpose of Components

### Arduino UNO
Main embedded controller responsible for gesture processing.

### Flex Sensor
Detects bending and gesture movement through resistance variation.

### LEDs
Provide gesture-based output indication.

### Breadboard & Jumper Wires
Used for hardware prototyping and sensor interfacing.
