# 🛠 Components Used

## Hardware Components

• Arduino UNO  
• Servo Motor  
• Potentiometer  
• Breadboard  
• Jumper Wires  
• USB Cable

---

## Purpose of Components

### Arduino UNO
Main embedded controller responsible for automation logic.

### Servo Motor
Provides controlled rotational movement.

### Potentiometer
Generates analog input values for angle control.

### Breadboard & Jumper Wires
Used for hardware prototyping and circuit setup.
