# 🌌 Overview

**HC-05 Bluetooth Automation System** was developed during the early experimentation phase of the SYGNIX journey as an exploration into wireless embedded communication and remote automation systems.

The project focused on understanding how Bluetooth modules could enable wireless interaction between smartphones and embedded hardware systems.

This prototype introduced foundational concepts such as:
- wireless communication
- Bluetooth interfacing
- remote automation
- embedded interaction systems
- smartphone-controlled electronics

The project became one of the earliest explorations into connected automation ecosystems.

# ⚙ Working Principle

The HC-05 Bluetooth module establishes wireless communication between a smartphone and Arduino system.

### Workflow

1. Smartphone sends Bluetooth commands.
2. HC-05 receives wireless data.
3. Arduino processes incoming instructions.
4. Outputs activate based on received commands.

This creates a basic Bluetooth-controlled embedded automation system.
