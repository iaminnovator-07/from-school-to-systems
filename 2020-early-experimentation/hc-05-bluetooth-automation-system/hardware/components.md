# 🛠 Components Used

## Hardware Components

• Arduino UNO  
• HC-05 Bluetooth Module  
• LEDs  
• Breadboard  
• Jumper Wires  
• Resistors  
• Smartphone  
• USB Cable

---

## Purpose of Components

### Arduino UNO
Main embedded controller handling automation logic.

### HC-05 Bluetooth Module
Enables wireless communication between smartphone and hardware.

### LEDs
Provide wireless automation output indication.

### Smartphone
Used to send Bluetooth commands.

### Breadboard & Jumper Wires
Used for hardware prototyping and circuit setup.
