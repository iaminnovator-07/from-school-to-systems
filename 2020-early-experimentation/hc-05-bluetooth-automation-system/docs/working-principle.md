# ⚙ Working Principle

The HC-05 Bluetooth Automation System enables wireless communication between a smartphone and embedded hardware.

---

# 📶 Bluetooth Communication

The HC-05 module receives wireless commands from a paired mobile device.

### Wireless Interaction
- Smartphone sends commands
- HC-05 receives Bluetooth data
- Arduino processes instructions
- Outputs respond automatically

---

# 🧠 Embedded Automation Workflow

```txt
Smartphone Commands
          ↓
 Bluetooth Communication
          ↓
      HC-05 Module
          ↓
   Arduino Processing
          ↓
    Automation Logic
          ↓
     Device Control
```

The system demonstrates basic wireless embedded automation and smartphone interaction concepts.
