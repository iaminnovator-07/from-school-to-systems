## Upload Process

1. Connect Arduino UNO through USB
2. Select correct COM Port
3. Select Arduino UNO board
4. Upload `.ino` source file
5. Pair HC-05 Bluetooth module with smartphone
6. Use Bluetooth terminal/mobile app for testing
