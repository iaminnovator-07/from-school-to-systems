# 🛠 Components Used

## Hardware Components

• Arduino UNO  
• LM35 Temperature Sensor  
• LEDs  
• Breadboard  
• Jumper Wires  
• Resistors  
• USB Cable

## Purpose of Components

### Arduino UNO
Main embedded controller handling monitoring logic.

### LM35 Temperature Sensor
Detects environmental temperature conditions.

### LEDs
Provide high-temperature visual indication.

### Breadboard & Jumper Wires
Used for hardware prototyping and sensor interfacing.
