# 🌌 Overview

**Temperature Monitoring System** was developed during the early experimentation phase of the SYGNIX journey as an exploration into environmental sensing and real-time monitoring architectures.

The project focused on understanding how temperature sensors could capture environmental data and enable continuous embedded monitoring workflows.

This prototype introduced foundational concepts such as:
- temperature sensing
- environmental monitoring
- real-time data acquisition
- embedded analytics
- sensor-driven monitoring systems

The project became one of the earliest explorations into intelligent environmental sensing architectures.

# ⚙ Working Principle

The system uses an LM35 temperature sensor to detect environmental temperature variations.

### Workflow

1. LM35 sensor continuously monitors temperature.
2. Arduino reads analog voltage values.
3. Embedded logic converts voltage into temperature readings.
4. Monitoring and alert workflows execute automatically.

This creates a basic embedded environmental monitoring system.
