# 🌌 Overview

**Smart Street Lights** was developed during the early experimentation phase of the SYGNIX journey as an exploration into intelligent public lighting systems and sensor-driven automation.

The project focused on understanding how embedded systems could automate environmental lighting using sensor-based logic and energy-efficient control mechanisms.

This prototype became one of the earliest explorations into:
- smart-city concepts
- environmental sensing
- intelligent automation
- embedded monitoring systems
- energy optimization logic

Although simple in implementation, the system introduced foundational engineering concepts that later evolved into larger-scale intelligent systems.

# 🚀 Core Features

### 🌃 Automatic Street Light Control
Street lights activate automatically during low-light conditions.

### 🌗 Ambient Light Detection
LDR sensor continuously monitors environmental brightness levels.

### 🚶 Motion-Based Detection
IR sensor detects nearby movement for dynamic light activation.

### 🔋 Energy-Efficient Logic
Lights operate only when required to reduce unnecessary power usage.

### 🧠 Embedded Automation Workflow
Arduino processes sensor inputs and controls automation logic.

# ⚙ Working Principle

The system uses:
- an LDR sensor for ambient light detection
- an IR sensor for motion sensing

### Workflow

1. LDR monitors surrounding brightness levels.
2. During nighttime conditions:
   - street lights become active
3. IR sensor detects nearby movement.
4. Lights activate dynamically based on motion detection logic.

This creates a basic intelligent street-lighting automation prototype.
