# 🌌 Introduction

2020 represents the foundational phase of the SYGNIX engineering journey.

This was the period where simple curiosity toward electronics gradually transformed into continuous experimentation with embedded systems, automation logic and sensor-driven prototypes during school years.

The projects developed during this phase were not focused on polished products or scalable architectures.

Instead, this phase was driven by:

- experimentation
- learning through building
- understanding system behavior
- exploring hardware interaction
- developing engineering curiosity

This became the origin point of long-term engineering exploration.
