# 🛠 Components Used

## Hardware Components

• Arduino UNO  
• Speaker Module  
• SD Card Module  
• Memory Card  
• 3D Printed Doll Structure  
• Jumper Wires  
• Breadboard  
• Power Supply Module  
• Audio Output Speaker

---

## Purpose of Components

### Arduino UNO
Main embedded controller responsible for audio playback logic and system control.

### SD Card Module
Stores recorded educational voice files and audio responses.

### Memory Card
Contains pre-recorded information about Maharashtra and interaction audio.

### Speaker Module
Outputs recorded voice and educational audio playback.

### 3D Printed Doll Structure
Physical interactive body structure of Aurora.

### Power Supply
Provides operational power to the embedded system.

### Breadboard & Jumper Wires
Used for hardware prototyping and embedded connections.
