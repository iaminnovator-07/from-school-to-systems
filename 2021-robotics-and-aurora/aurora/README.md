# 🌌 Overview

**Aurora** was one of the earliest interactive embedded-system projects developed during the robotics and innovation phase of the SYGNIX journey.

The project was designed as an educational talking assistant built inside a custom 3D-printed doll structure.

Aurora used:
- Arduino
- speaker modules
- memory card module
- pre-recorded audio responses

to create an interactive system capable of speaking stored information about Maharashtra.

When powered ON, Aurora would automatically play recorded educational content and interaction audio through the embedded speaker system.

This project represented:
- one of the first explorations into interactive embedded systems
- educational automation concepts
- human-device interaction
- audio-based assistant architectures

Aurora later became the conceptual inspiration for:
- Aurora 2.0
- intelligent assistant systems
- AI ecosystem concepts
- future SYGNIX architectures

Although simple in implementation, Aurora became one of the most memorable foundational projects in the engineering journey.

# ⚙ Working Principle

Aurora used a memory card module to store recorded voice files.

### Workflow

1. System powers ON.
2. Arduino initializes audio system.
3. Stored voice recordings are accessed from memory card.
4. Audio playback is sent through speaker module.
5. Educational information about Maharashtra is spoken automatically.

This created a basic interactive educational embedded assistant system.
