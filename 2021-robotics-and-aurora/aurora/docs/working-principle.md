# 🌌 Workflow

```txt
Power ON
    ↓
Arduino Processing
    ↓
Audio File Access
    ↓
Speaker Playback
    ↓
Educational Voice Output
```

The system automatically played stored educational audio about Maharashtra through embedded speaker systems.
