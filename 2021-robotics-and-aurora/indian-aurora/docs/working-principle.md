# ⚙ Working Principle

Indian Aurora functioned as an interactive educational assistant system using embedded audio playback and Bluetooth communication.

---

# 🇮🇳 Workflow

```txt
User Interaction
        ↓
 Mobile App / Bluetooth
        ↓
 Arduino Processing
        ↓
 Audio File Access
        ↓
 PAM8403 Amplification
        ↓
 Educational Audio Output
```

The system delivered:
- educational information about Indian states
- interactive responses
- portable embedded interaction

through upgraded hardware architecture.
