# 🌌 Overview

**Indian Aurora** was the upgraded evolution of the original Aurora project developed during the robotics and innovation phase of the SYGNIX journey.

The project transformed Aurora from:
```txt
a simple talking educational doll
```

into:
```txt
a portable interactive educational assistant system
```

Indian Aurora featured:
- upgraded 3D-printed structure
- embedded speaker system
- PAM8403 audio amplifier
- Bluetooth module integration
- rechargeable battery system
- charging port support
- mobile application connectivity

The system was designed to provide:
- educational information about Indian states
- interactive voice responses
- portable embedded interaction
- audio-based educational assistance

through an upgraded embedded ecosystem architecture.

# ⚙ Working Principle

Indian Aurora used embedded audio systems and Bluetooth interaction for educational communication.

### Workflow

1. User interacts through app or embedded controls.
2. Bluetooth module sends communication data.
3. Arduino processes interaction logic.
4. Audio files are accessed and processed.
5. PAM8403 amplifier boosts speaker output.
6. Educational information and interaction audio are played.

This created a portable interactive educational assistant ecosystem.
