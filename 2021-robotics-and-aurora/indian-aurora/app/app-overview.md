# 📱 Mobile Application Overview

The Indian Aurora mobile application was designed to:
- provide educational interaction
- access information about Indian states
- trigger audio responses
- communicate through Bluetooth

---

# ⚡ Core App Features

• State information access  
• Bluetooth communication  
• Interactive controls  
• Educational audio triggering  
• Embedded system interaction  

---

# 🌌 App Concept

The application represented one of the earliest explorations into:
- app-connected embedded systems
- educational mobile interaction
- wireless embedded ecosystems
